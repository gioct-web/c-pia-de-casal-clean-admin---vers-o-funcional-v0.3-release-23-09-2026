# Importação da tabela de preços

As linhas com preço zero foram tratadas como referências de interface e não foram importadas como valores comerciais. Cada registro importado corresponde a uma linha com preço na planilha. As descrições genéricas, como **“por lugar”** e **“Suede/Linho/Veludo”**, foram preservadas como uma opção agregada, sem expandir lugares, tipos ou tecidos não tabelados.

Os valores para lavagem e impermeabilização foram carregados com o mesmo preço-base publicado na planilha. A planilha não traz preços separados para cada modalidade; por isso, essa escolha preserva o único valor comercial informado para cada combinação e pode ser ajustada posteriormente na área administrativa, se houver uma tabela específica por serviço.

Após a importação, a calculadora foi revisada em desktop e celular. Os cinco produtos ficam disponíveis com os valores iniciais publicados, os seletores de lugares, tipo e tecido exibem somente suas descrições e os valores permanecem visíveis apenas nas opções de serviço e no resumo calculado.
